<p color="#821eez">Here you'll find the components made in just HTML, CSS & JS, so even a beginner can use.</p
<p color="#821eez">In the folder <span color="rgb(150,90,209)">Toggle</span> you'll find two folders one <span color="rgb(150,90,209)">advancetoggle</span> and the second one <span color="rgb(150,90,209)">normal toggle</span>, the <span color="rgb(150,90,209)">advance toggle</span> changes the color to the random linear gradient RGB colors both for light theme and the dark theme and when refreshed comes back to its original color & the <span color="rgb(150,90,209)">normal toggle</span> changes the color into a dark or light version of a same rgb color means dark or light ambiance.</p>
